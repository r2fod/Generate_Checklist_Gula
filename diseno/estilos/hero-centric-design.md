# Estilo: Hero-Centric Design
> Tipo: Landing Page · Origen: 2020s Modern · Complejidad: Medium · ID: `hero-centric-design`

- **Palabras clave**: Large hero section, compelling headline, high-contrast CTA, product showcase, value proposition, hero image/video, dramatic visual
- **Colores primarios**: Brand primary color, white/light backgrounds for contrast, accent color for CTA
- **Colores secundarios**: Supporting colors for secondary CTAs, accent highlights, trust elements (testimonials, logos)
- **Efectos y animación**: Smooth scroll reveal, fade-in animations on hero, subtle background parallax, CTA glow/pulse effect
- **Ideal para**: SaaS landing pages, product launches, service landing pages, B2B platforms, tech companies
- **No usar en**: Complex navigation, multi-page experiences, data-heavy applications
- **Modo claro**: supported
- **Modo oscuro**: supported
- **Rendimiento**: cost:low|drivers:none
- **Accesibilidad**: risk:low|requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion
- **Móvil**: native
- **Conversión**: ✓ Very High
- **Palabras para prompt**: Design a hero-centric landing page. Use: full-width hero section, compelling headline (60-80 chars), high-contrast CTA button, product screenshot or video, value proposition above fold, gradient or image background, clear visual hierarchy.
- **Palabras CSS**: min-height: 100vh, display: flex, align-items: center, background: linear-gradient or image, text-shadow for readability, max-width: 800px for text, button with hover scale (1.05)
- **Checklist de implementación**: ☐ Hero section full viewport height, ☐ Headline visible above fold, ☐ CTA button high contrast, ☐ Background image optimized (WebP), ☐ Text readable on background, ☐ Mobile responsive layout
- **Variables de diseño**: --hero-min-height: 100vh, --headline-size: clamp(2rem, 5vw, 4rem), --cta-padding: 1rem 2rem, --overlay-opacity: 0.5, --text-shadow: 0 2px 4px rgba(0,0,0,0.3)
- **Estado**: deprecated
