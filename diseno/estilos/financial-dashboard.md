# Estilo: Financial Dashboard
> Tipo: BI/Analytics · Origen: 2020s Modern · Complejidad: Medium · ID: `financial-dashboard`

- **Palabras clave**: Revenue metrics, profit/loss visualization, budget tracking, financial ratios, portfolio performance, cash flow, audit trail
- **Colores primarios**: Financial colors: profit (green #22C55E), loss (red #EF4444), neutral (grey), trust (dark blue #003366)
- **Colores secundarios**: Revenue highlight (green), expenses (red), budget variance (orange/red), balance (grey), accuracy (blue)
- **Efectos y animación**: Number animations (count-up), trend direction indicators, percentage change animations, profit/loss color transitions
- **Ideal para**: Financial reporting, accounting dashboards, portfolio tracking, budget monitoring, banking analytics
- **No usar en**: Simple business dashboards, entertainment/social metrics, non-financial data
- **Modo claro**: supported
- **Modo oscuro**: supported
- **Rendimiento**: cost:low|drivers:none
- **Accesibilidad**: risk:low|requires:contrast-text-4.5,keyboard,visible-focus,reduced-motion
- **Móvil**: not-recommended
- **Conversión**: ✗ Not applicable
- **Palabras para prompt**: Design a financial dashboard. Use: revenue/expense charts, profit margins, budget vs actual, cash flow waterfall, financial ratios, audit trail table, currency formatting, period comparisons.
- **Palabras CSS**: number formatting (Intl.NumberFormat), waterfall chart (positive/negative bars), variance coloring, table with totals row, sparkline for trends, sticky column headers
- **Checklist de implementación**: ☐ Currency formatted, ☐ Decimals consistent, ☐ P&L clear, ☐ Budget variance shown, ☐ Audit trail complete, ☐ Export to Excel
- **Variables de diseño**: --currency-symbol: $, --decimal-places: 2, --profit-color: #22C55E, --loss-color: #EF4444, --variance-threshold: 10%, --table-header-bg: #F3F4F6
- **Estado**: supplemental
